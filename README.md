Portfolio of Denis Novik

Это статичное портфолио, созданное для Denis Novik — UX/UI дизайнера. На данный момент сайт отображает основную информацию о дизайнере, его навыках и примерах работ. Это проект для демонстрации дизайнера и его профессиональных достижений.
О проекте

Страница включает:

    Обо мне: информация о дизайнере, его профессиональном пути и увлечениях.
    Навыки: с иконками программ и рейтингом уровня владения ими.
    Портфолио: изображения и примеры работ дизайнера.

Текущий функционал:

    Адаптивный дизайн: страница корректно отображается на различных устройствах, включая мобильные телефоны и десктопы.
    Статичная структура: в проекте пока нет динамических элементов, только визуальные блоки с информацией.
    Секции с иконками программ: для демонстрации навыков дизайнера в таких программах, как Photoshop, After Effects и Figma.

Предстоящие функции:

    Бургер-меню: в будущем будет добавлено бургер-меню для удобной навигации на мобильных устройствах. Это улучшит пользовательский опыт и позволит более комфортно перемещаться по страницам на маленьких экранах.

Технологии:

    HTML/CSS: для создания структуры и стилей страницы.
    JavaScript: для добавления интерактивных элементов, таких как бургер-меню.
    SVG иконки: для отображения логотипов программ.

Установка:

    Клонируйте репозиторий:

    git clone https://github.com/yourusername/portfolio.git

    Откройте проект в браузере: Откройте index.html в любом браузере, чтобы увидеть страницу в действии.

    В дальнейшем будет добавлено бургер-меню и другие функциональные улучшения.
